# Knerd hero reference

This is the selected **C — Follow the pull** reference from the Star LP motion review.
The reviewed source is `star-lp-motion-lab` commit `f89a3235f0b6cc20bd57c7477d7a1693bb2c228a`.

The demo is isolated in an iframe so its viewport fitting and pointer coordinates match the approved draft.
`preset.js` is imported by both the demo and `/dev/ds/marketing/knerd`; there are no alternative motion presets.
`hero.js` preserves the reviewed sizing, keyframes, magnetic equations and lifecycle behavior.
The only port changes are the selected preset, local imports and font URLs.

This is a design reference, not a production LP component. Existing pages keep using `Title`.
A production hero port must retain the whole specification, including copy clearance, reduced motion,
500ms touch pulses, offscreen suspension, and stable letter anchors.

The demo CTA is nonfunctional and shown only for composition.
The six phrases are examples from the reviewed draft, not a new source of product claims.
